# W4.1: Attack Catalogue

The ground truth behind this catalogue is `features/raw_12f.csv`, with each row extracted from the last, post-rewrite, AMF-facing (port-38413) `UERadioCapabilityInfoIndication` frame per registration event (see `collect_real_handset.py`/`collect_ueransim.py`'s `rows[-1]` selection, and Bug 16 for why the post-rewrite frame is the one that matters). The excluded a56 profile (Bug 21) is dropped from every count below, whilst the IE field paths are taken directly from `proxy/ngap_decode.py`'s `STAGE2_MODIFIERS` implementations rather than guessed.
